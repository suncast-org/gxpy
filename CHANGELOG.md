# Changelog

## 0.1.0a1

First alpha of GXpy, the umbrella installation package for the GX Simulator Python ecosystem.

- Install pyAMPP, pyGXRender, pyEUVTools, and pyCHMP through one metapackage.
- Declare initial compatibility ranges for Python 3.12 and later.
- Document component purposes, imports, and independent EBTEL downloads.
- Provide package-build checks, component smoke checks, and PyPI trusted-publishing automation.

GXpy contains no new scientific implementation and does not bundle datasets.
